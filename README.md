# 🐱 MonttiMoney

Персональный Telegram-бот для учёта личных финансов.

MonttiMoney позволяет вести учёт доходов и расходов обычными сообщениями в Telegram без таблиц и сложных приложений.

---

## ✨ Возможности

- 💰 Учёт доходов и расходов
- 💳 Учёт кредитной карты
- 📅 Обязательные ежемесячные расходы
- 🎯 Накопительные цели
- 📜 История операций
- 📊 Статистика по расходам
- 🧠 Автоматическое запоминание категорий
- ↩️ Отмена последней операции
---

## 💬 Примеры использования

Доход:

```text
Зарплата 50 000
```

Обычный расход:

```text
Продукты 1 500
```

Расход с кредитной карты:

```text
Кофе с кредитки 300
```

Погашение кредитной карты:

```text
Внесла на кредитку 5 000
```

---

## 💳 Как работает кредитка

На главном экране отображаются:

- лимит кредитной карты;
- сколько потрачено;
- сколько осталось доступно.

Покупки с кредитки сохраняются в истории и статистике, но не уменьшают основной баланс.

## 🚀 Запуск

1. Создать файл `.env`
2. Установить зависимости:

```bash
pip install -r requirements.txt
```

3. Запустить бота:

```bash
python bot.py
```
